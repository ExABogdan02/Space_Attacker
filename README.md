# Space Attacker

Space Attacker is a simple 2D game made for a university project on data structures.
The game is written in C++ and uses the raylib library for graphics, input handling, text rendering, and basic game functionality. The project also uses a simple linked list to manage the projectiles fired by the player.
The player controls a spaceship (small shape for now), shoots enemies, and tries to survive for as long as possible. The player has 4 lives, and the enemies become faster after every 3 points. The game can also be restarted after losing.
Future updates will include different enemy types, boss fights, multiple enemies on screen, improved graphics, and sound effects.

## Requirements

- C++ Compiler
- Raylib
